# HUD / UI target concepts

Reference art for the target game feel of the HUD (dropped 2026-07-18).
These define where HUD elements should ultimately live; the tracking issue
holds the full element-by-element notes.

- `UI-Game-Feel.png` — annotated "HUD improvements" mock: one in-game frame
  with every target HUD element labeled (scoreboard, kill feed, objective
  markers, player status card, ability/equipment bar, weapon panel, radar).
- `more-ui-examples.png` — the same HUD shown across six map locations
  (consistency reference), plus a bottom strip with loadout panel, round
  info, and network/FPS readouts. Environment style doubles as an iceworld
  kit fidelity target (`FY_ICEWORLD`).
